Main finding

Skills turn a generic RAG into a workflow agent.

Three short prompts — Trace, Decide, Onboard — re-route hybrid retrieval and reasoning into structured outputs the user can act on, without changing the underlying retriever.

Why it matters

Default RAG fails in 3 ways

  1. Loses chronology. Summarises the highest-scoring doc; drops the time dimension a user needs to trace an incident.
  2. Loses outcomes. Recaps the debate when asked "what did we decide" — the actual decision often lives in one later message.
  3. Single-angle. Onboarding questions need several searches (status, team, blockers); a default agent runs one and stops.

Better retrieval alone doesn't fix these — they're workflow failures.

How it works

Skill prompts steer the agent loop

Each skill is a numbered workflow prepended to the user message at send time. The same hybrid retriever; new instructions on how to use it.
